## Orden de lectura
1. **`KODEX-OS-CONCEPT.md`** — el NORTE. Qué es KODEX: un visualizador/instrumento (paradigma
   Winamp/MilkDrop) donde la obra se vuelve visualización, cada escena = preset, datos = piel.
2. **`KODEX-STORYBOARD-CONTENT.md`** — el CONTENIDO real: 6 estratos + copy verdadera de Ocin
   (inglés universal + acentos de escrituras del mundo por estrato). No inventar copy.
3. **`KODEX-LIVING-ARCHITECTURE.md`** — la RECETA técnica: motor `kodexAudio` + shaders ya existen,
   solo hay que conectarlos; tabla "una gramática, escenas distintas"; matar el ojo; negro dominante.
4. **`KODEX-TRANSLATION-MAP.md`** — concepto→píxel por escena.
5. **`kodex-grammar/`** — sistemas listos: `system-v1` (grids/motion/recetas), `kodex-typography-system-v2`
   (Barlow Condensed + IBM Plex Mono + Inter Tight), `kodex-open-visual-lab-v1` (8 shaders).
