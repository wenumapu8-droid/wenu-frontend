# KODEX HEART ENGINE

Status: `CANONICAL / SPECIFICATION`

## Principle

> THE HEART DOES NOT SCORE. IT ORIENTS.

The heart is the living center of KODEX−∞. It coordinates attention, optional breathing, visual rhythm and safe return. It never claims to measure spiritual value, emotional frequency or clinical coherence without real instruments and validated methods.

## Core modes

### Guided pulse

```yaml
mode: GUIDED_PULSE
classification: SYNTHETIC
label: GUIDED / NOT MEASURED
bpm_default: 60
user_adjustable: true
```

Purpose:

- provide a calm external rhythm;
- synchronize visual, sound and transition timing;
- reduce interaction pressure;
- prepare the user for RETURN.

### Tap pulse

```yaml
mode: TAP_PULSE
classification: USER_INPUT_DERIVED
label: APPROXIMATE TAP TEMPO / NOT MEDICAL
minimum_taps: 4
```

Purpose:

- allow the user to introduce a perceived or chosen rhythm;
- personalize animation tempo;
- never present the result as ECG, heart rate diagnosis or biometric truth.

### Sensor pulse

```yaml
mode: SENSOR_PULSE
status: DISABLED
```

It remains disabled until implementation includes:

- real supported device;
- explicit consent;
- device and signal metadata;
- signal-quality indicator;
- data retention policy;
- behavior during lost signal;
- privacy review;
- non-medical disclosure;
- human safety review.

## Visual behavior

The heart may control:

- scale pulse;
- light intensity;
- line propagation;
- relation activation;
- sound envelope;
- transition timing;
- spectral opening toward `RETURN / +∞`.

It must not generate fake ECG waves or imply anatomical measurement.

## Breath behavior

Default public mode:

```yaml
breath:
  style: gentle_optional_guidance
  inhale_seconds: 5
  exhale_seconds: 6
  hold_seconds: 0
  natural_breath_alternative: always_available
```

The timing is a design prompt, not a medical prescription. The user can pause, stop, disable guidance or return to natural breathing at any moment.

## Required controls

- `START`
- `PAUSE`
- `STOP`
- `NATURAL BREATH`
- `MOTION: FULL / REDUCED / OFF`
- `SOUND: ON / OFF`
- `EXIT TO RETURN`

Controls must remain keyboard accessible and visible during the experience.

## Stop guidance

The experience must instruct the user to stop if they feel dizzy, faint, panicked, disoriented or unwell. Distress is never interpreted as progress.

## Relationship to the state spectrum

The Heart Engine does not force an upward ladder. It can support several adaptive functions:

- `REPLIEGUE`: minimal motion and grounding;
- `GUARDIA`: clear perimeter and exits;
- `EQUILIBRIO`: regular guided rhythm;
- `INTEGRACION`: layered but stable pulse relations;
- `QUIETUD`: reduced amplitude and spatial silence;
- `RADIANCIA`: white field and spectral opening.

## Return sequence

```text
PULSE
→ SLOWER VISUAL RESPONSE
→ NATURAL BREATH
→ NOTICE BODY AND ROOM
→ ORDINARY TIME
→ PATH MEMORY
→ SOURCES
→ WHITE / PURE SPECTRUM

```

## Acceptance criteria

- no fabricated biometric value;
- guided pulse clearly labeled synthetic;
- natural breathing option always present;
- reduced-motion mode complete;
- no strobing or forced audio;
- immediate stop and exit;
- heart state affects the final artifact;
- path can continue without using the contemplative module.
