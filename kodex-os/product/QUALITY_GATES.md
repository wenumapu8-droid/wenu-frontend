# KODEX−∞ QUALITY GATES

Status: `CANONICAL / BOOTSTRAP`

A KODEX module or experience cannot be considered release-ready until it passes all applicable gates.

## Gate 1 — Canon

- [ ] Reads the current canon and does not invent parallel terminology.
- [ ] Has a named node, module or work packet.
- [ ] Updates current state or decision records when required.
- [ ] Does not contradict a non-negotiable rule.

## Gate 2 — Information integrity

- [ ] Every essential visual element has a declared meaning.
- [ ] Sources, units, denominators, formulas and scope exist where applicable.
- [ ] Evidence, interpretation, speculation, myth and atmosphere are distinguishable.
- [ ] Missing or contradictory information is represented honestly.
- [ ] No pseudo-metrics, fabricated biometrics or fake scientific instrumentation.

## Gate 3 — Comprehension

- [ ] A first-time user can identify the question being explored.
- [ ] Hierarchy, labels, legends and annotations are sufficient.
- [ ] The piece communicates without relying on aesthetic explanation from its creator.
- [ ] Complexity is progressive rather than simultaneous.
- [ ] A non-visual or textual explanation exists for complex graphics.

## Gate 4 — Experience graph

- [ ] User decisions create different consequences.
- [ ] Session memory preserves relevant choices.
- [ ] The node has meaningful entry and exit conditions.
- [ ] Convergence contributes to `RETURN / +∞`.
- [ ] Re-entry opens a genuinely different relation or path.

## Gate 5 — Visual system

- [ ] Composition is intentional at mobile and desktop sizes.
- [ ] Typography is legible and rights-cleared.
- [ ] Color is not the only carrier of meaning.
- [ ] Atmosphere is declared and does not imitate data.
- [ ] The black-to-white/spectral transformation is used only when narratively justified.
- [ ] The result feels strange and advanced without becoming visually noisy.

## Gate 6 — Motion and sound

- [ ] Motion encodes state, change, attention or declared atmosphere.
- [ ] Reduced-motion and motion-off modes are complete.
- [ ] No strobing or unexpected high-intensity transitions.
- [ ] Audio is optional, controllable and captioned or described when meaningful.
- [ ] Loops are seamless when presented as loops.
- [ ] The experience remains understandable without sound.

## Gate 7 — Accessibility

- [ ] Keyboard navigation is complete.
- [ ] Focus state is visible.
- [ ] Controls have accessible names.
- [ ] Screen-reader alternatives exist.
- [ ] Contrast is adequate.
- [ ] Touch targets are usable on mobile.
- [ ] Immediate exit and pause are always available.
- [ ] Language does not shame or rank the user.

## Gate 8 — Cultural responsibility

- [ ] Attribution and provenance are complete.
- [ ] Public/restricted/authorization-required status is recorded.
- [ ] No generic sacred-symbol synthesis.
- [ ] No claim of community authority without authorization.
- [ ] Human cultural review completed when required.
- [ ] Sensitive material remains outside the public layer.

## Gate 9 — Contemplative safety

- [ ] Participation is optional.
- [ ] Natural breathing is always available.
- [ ] Guided pulse is labeled synthetic when not measured.
- [ ] No medical, therapeutic or spiritual attainment claims.
- [ ] Pause, stop, grounding and return are visible.
- [ ] Distress is never framed as progress.
- [ ] The core path remains usable without contemplation.

## Gate 10 — Engineering

- [ ] Build passes.
- [ ] Type and lint checks pass when configured.
- [ ] Automated tests cover critical logic.
- [ ] Visual regression or screenshots exist for visual work.
- [ ] Performance is acceptable on representative mobile hardware.
- [ ] Fallbacks exist for unavailable WebGL, sensors or audio.
- [ ] No secrets or personal data are committed.
- [ ] Dependencies and licenses are reviewed.

## Gate 11 — Open source and rights

- [ ] Public code is separated from private knowledge.
- [ ] Third-party assets have redistribution permission.
- [ ] Generated assets include provenance.
- [ ] Repository links and download behavior are accurate.
- [ ] Licensing boundaries are visible.

## Gate 12 — Release

- [ ] PR explains purpose, consequences, tests, risks and provenance.
- [ ] Human review completed.
- [ ] Rollback path exists.
- [ ] Deployment target verified.
- [ ] Exact approval phrase `APROBAR DEPLOY` has been provided.

Without the final phrase, deployment status remains `BLOCKED`.
