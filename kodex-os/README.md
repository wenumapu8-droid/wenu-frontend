# KODEX−∞ — Canonical Operating System

KODEX−∞ is a living information system: an interactive, generative archive that transforms evidence, memory, culture, symbols and contemplative practices into explorable experiences.

This directory is the temporary canonical staging area inside `wenu-frontend`. The intended permanent home is the dedicated private repository `wenumapu8-droid/kodex-minus-infinity`.

## Core thesis

> Information is not displayed. It is embodied.

> The archive does not store. It remembers.

> Every path preserves memory. Every convergence changes the observer.

## Experience invariant

```text
−∞ / BLACK / FRAGMENTATION
        ↓
THRESHOLD
        ↓
USER DECISIONS + UNIQUE PATH
        ↓
ARCHIVE / MACHINE / HEART / COSMOLOGY
        ↓
RETURN / +∞
        ↓
WHITE + PURE SPECTRAL COLOR
        ↓
REFLECTION / CONTRIBUTION / SHARING / RE-ENTRY
```

`RETURN / +∞` is not a redirect or decorative ending. It is the semantic convergence of the path: provenance becomes visible, relationships become legible, the generated artifact becomes shareable, and another route opens.

## Repository rules

- Work on a branch and submit a pull request.
- Never create parallel terminology without recording a decision.
- Never fabricate data, biometrics, frequencies or cultural authority.
- Separate evidence, interpretation, speculation and myth.
- Do not deploy without the exact phrase `APROBAR DEPLOY`.
- Keep private conversations, personal data and rights-unclear assets out of the public product layer.

## Status vocabulary

Every artifact must be classified as one of:

- `CANONICAL`
- `APPROVED`
- `EXPERIMENTAL`
- `REFERENCE`
- `SUPERSEDED`
- `DEPRECATED`
- `PRIVATE`
- `RIGHTS_UNCLEAR`
