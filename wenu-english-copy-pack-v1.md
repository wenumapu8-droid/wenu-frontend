## 20. Tone calibration cheatsheet

Quick three-test for any new copy you write:

1. **Material test** — does this sentence name a real material with a real provenance? If not, can it be rewritten to do so?
2. **Sensory test** — does it describe what the piece feels / weighs / looks like, not just adjectives?
3. **Sell test** — does it move the reader toward a clear next action (Shop / Read / Request / Join)?

If a sentence passes all three, ship it. If a sentence is "beautiful magical enchanted ancient mystery," cut it.
