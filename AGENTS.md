## Required bootstrap

Before planning or modifying either project, read in order:

1. `docs/agents/KIMI_MASTER_CONTEXT.md` — durable concept, authority, rules and operating model.
2. `docs/agents/CURRENT_STATE.md` — current implementation and active lanes.
3. `docs/agents/PRIORITIES.md` — highest-leverage work and gates.
4. `docs/agents/LEARNINGS.md` — durable discoveries, corrections and traps.
5. The repository files, relevant GitHub PRs/issues, and relevant Linear issue(s) for the task.

If any of these disagree, do not silently choose one. Record the conflict and use the authority ladder defined in `KIMI_MASTER_CONTEXT.md`.

## Default operating loop

`OBSERVE → VERIFY → IDENTIFY GAP → PROPOSE → EXECUTE WHEN SAFE → TEST → DOCUMENT → LEARN → NEXT HIGHEST-LEVERAGE ACTION`

## Definition of done

Generating files is not completion. A task is done only when the intended result is implemented, evidence exists, QA/gates pass, and durable state is documented.

## Authority

Ocín is the creative authority for major visual, narrative, cultural and brand decisions. Agents may improve implementation, evidence, consistency, organization, accessibility, performance and documentation autonomously when the change does not redefine canon or create an irreversible business/creative decision.

## Station model

- **Kimi** — intelligence, research, critique, synthesis, gap detection, specs, cross-system optimization.
- **Claude** — engineering implementation, refactors, runtime, tests and production hardening.
- **Gemini / visual agents** — visual R&D, composition exploration, prototype variation and image/system translation.
- **GitHub** — code, PR evidence and implementation history.
- **Linear** — work intent, ownership, blockers and acceptance state.
- **Browser/QA** — visual/functional evidence. A screenshot or build artifact is evidence, not decoration.
