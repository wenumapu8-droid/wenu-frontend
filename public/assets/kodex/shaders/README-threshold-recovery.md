# Threshold GPU Recovery

`threshold-portal-recovered.frag.glsl` is the authored KODEX Open Visual Lab V1 Threshold fragment shader recovered from the project asset corpus for KOD-49 reuse.

It is intentionally preserved as a recovery baseline rather than silently rewritten. The KOD-49 comparison lab mounts it through a new repo-native WebGL2 feedback runtime.

This is a non-production visual recovery asset. Final palette/material/state tuning must be judged against the approved KODEX Threshold references and must preserve semantic/epistemic constraints from the P0 Scene Bible.
