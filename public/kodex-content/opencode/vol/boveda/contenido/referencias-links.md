## 2026-07-31 — El eslabón: visualizadores de música (Winamp/MilkDrop, Windows XP)

Ocin identificó el concepto que cose KODEX: los "efectos infinitos que se mueven con la música" de
Windows XP / Winamp = **music visualizers**. Canónicos: **MilkDrop** (Winamp) y las visualizaciones de
**Windows Media Player**, ambos de **Ryan Geiss**. Técnica = FFT + beat detection → shaders/generadores
de patrón; cada look = un **"preset"**. **KODEX = ese paradigma**: motor audio-reactivo (ya tenemos
`kodexAudio` FFT) + escenas como presets + chrome dossier como skin. Síntesis completa en
`wenu-frontend/KODEX-OS-CONCEPT.md` (y copiado al Mac mini). Ver [[project_kodex_norte_visual]].
- MilkDrop (Geisswerks): http://www.geisswerks.com/milkdrop/
- Cómo funcionan las visualizaciones WMP (FFT → gráficos).
