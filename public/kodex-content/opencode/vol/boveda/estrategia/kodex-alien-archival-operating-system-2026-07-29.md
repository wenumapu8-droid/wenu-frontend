# KODEX −∞ — Alien Archival Operating System

> Definición congelada por Ocin. KODEX no es una web cyberpunk, ni un portfolio con HUD, ni un dashboard futurista, ni una NFT website. Es un **sistema operativo artístico de origen desconocido**, diseñado para almacenar, interpretar y transformar patrones vivos.

## Identidad correcta

La estética correcta queda definida como:

- **Alien Archival Operating System**
- **Neo-Ancestral Cosmic Interface**
- **Retrofuturist Living Artifact Protocol**

### Qué NO es

- no “dashboard futurista”
- no “NFT website”
- no “sitio oscuro con círculos”
- no “HUD sci-fi” como protagonista
- no “portfolio tech” con controles por deporte

### Qué SÍ debe sentirse

La obra debe sentirse **como si hubiese sido encontrada dentro de una tecnología ajena**.

## Aportes clave de las referencias nuevas

### 1. Victor Ketom — universo, legitimidad y venta

Lo que aporta:
- la obra como **artefacto**, no como “contenido”
- colecciones con conceptos distintos, no una galería infinita
- procedencia, técnica, año, estado y certificado
- venta directa elegante
- NFT/blockchain como capa secundaria
- drops limitados solo si existe edición real
- declaración artística concreta y creíble

**Lectura para KODEX:** todavía faltaba demostrar que este universo puede materializarse y comprarse con legitimidad.

### 2. Nigina — interacción simple y viva

Lo que aporta:
- primera reacción en menos de 1 segundo
- interacción táctil y por cursor
- la imagen como sistema dinámico
- controles contextuales, no paneles permanentes
- pocos parámetros, pero visibles de verdad
- jugar primero, comprender después

**Traducción para KODEX:** dentro de `SIGNAL CONTROL` bastan 3 parámetros:
- `DENSITY`
- `MEMORY`
- `DISTORTION`

No veinte sliders. Esto no es la cabina de un Boeing alienígena.

## Cómo debe funcionar KODEX

## El shell

Una aplicación persistente de `100dvh`, sin scroll narrativo vertical.

```text
KODEX SHELL
├── Signal Core
├── Living Artwork
├── Journey Ring
├── Context Layer
├── Artifact Tab
└── Navigation
```

La interfaz permanece. El mundo interior cambia.

## El círculo

El círculo deja de ser decoración y se convierte en el **KODEX Depth Engine**.

### Capas del círculo

- **Anillo exterior** → 7 capítulos / navegación
- **Anillo intermedio** → estado, profundidad y progreso
- **Núcleo** → obra viva seleccionada
- **Órbitas** → proyectos y relaciones
- **Puntos** → señales descubiertas

### Regla

Al avanzar, no cambia una página. **El círculo rota, la cámara entra y el núcleo muta.**

## Capítulos / mapa / progreso

Cambiar:
- `01 / 07 UMBRAL`

Por:
- `NODE 00`
- `THRESHOLD`
- `DISCOVERED 00%`

El progreso debe crecer cuando la persona **interactúa de verdad**, no solo cuando avanza linealmente.

## Las capas de profundidad

### Nivel 0 — Contemplación
Solo obra, título y acción.

### Nivel 1 — Interacción
Cursor, touch, sonido o movimiento alteran la obra.

### Nivel 2 — Información
Se abre dossier con contexto y procedencia.

### Nivel 3 — Colección
Aparecen edición, disponibilidad y licencia.

**Principio:** la persona decide cuánto profundizar. El sitio no le arroja todo encima al comienzo.

## Artifact Tab (sistema de esquina)

Se confirma como componente canónico:

### Estado en reposo
Solo muestra símbolo.

### Estados posibles
- `◈ EDITION`
- `∞ ON-CHAIN`
- `◇ AVAILABLE`
- `× ARCHIVED`

### Al tocarlo
```text
ARTIFACT KDX_A_007
ARCHIVE WORK
EDITION 03 / 12
PROVENANCE VERIFIED

[ OPEN DOSSIER ]
```

### Dentro del dossier
- `VIEW ARTWORK`
- `READ PROTOCOL`
- `VIEW PROVENANCE`
- `COLLECT EDITION`

### Comportamiento por dispositivo
- **móvil:** bottom sheet
- **desktop:** panel lateral superpuesto

## Diferencia entre móvil y desktop

## Móvil

```text
HEADER                 56 px
HERO ARTWORK           52–58 svh
HEADLINE               2 líneas
DESCRIPTION            1–2 líneas
PRIMARY CTA            52–56 px
JOURNEY NAVIGATION     48–56 px
```

Reglas:
- una interacción táctil central
- sin metadata permanente
- Artifact Tab de 36 px
- dossier como bottom sheet
- sin retículas microscópicas
- sin serif fina ilegible
- sin contenido apareciendo debajo del viewport

## Desktop

- retícula de 12 columnas
- obra: 7–8 columnas
- mensaje: 3 columnas
- metadata: 1 columna
- Artifact Tab en esquina superior derecha de la obra
- movimiento espacial suave
- cursor como herramienta de escaneo
- Index como mapa orbital fullscreen

## Tres estados de interfaz

### DORMANT
Oscuro, silencioso, poca información.

### AWARE
La obra detecta presencia y revela señales.

### OPEN
Aparecen dossiers, archivo, procedencia y posibilidades comerciales.

**Problema actual resuelto por esta decisión:** la primera pantalla estaba permanentemente en `OPEN`, mostrando demasiado antes de que la persona hiciera algo.

## Aplicaciones exactas de las referencias núcleo

### Active Theory
La interacción deja huella.

- el usuario deja un rastro en el sistema
- su recorrido modifica la obra
- `Machine` produce un resultado derivado
- `Return` muestra un artifact personal guardable

**Regla:** el resultado no puede ser completamente aleatorio; debe recordar cómo actuó el visitante.

### Lusion
- una sola escena WebGL persistente
- cámara que cambia profundidad entre capítulos
- las obras entran y salen del mismo espacio
- no cargar una página distinta para cada folio
- transiciones materiales: disolución, repliegue, órbita, regeneración

**Regla:** KODEX debe parecer una sola máquina que cambia de estado.

### Penderecki’s Garden
- el círculo funciona como mapa del sistema
- cada capítulo es un nodo
- se muestra progreso de descubrimiento
- el Index es visual y espacial
- pueden existir señales ocultas opcionales

### SMSY Gen-02
- sensación de territorio digital
- objetos que funcionan como portales
- interfaces flotantes vinculadas a elementos reales
- proyectos convertidos en sectores del universo
- navegación espacial en desktop

**Guardrail:** no copiar su densidad completa en móvil; ahí KODEX debe quedar en una versión 2.5D más contenida.

### Feral File / Verse
- `Exhibition` antes que `Shop`
- obra a tamaño completo
- curaduría separada de venta
- formato digital indicado claramente
- procedencia y colección sin estética cripto
- usar `COLLECT`, `EDITION`, `PROVENANCE`
- mostrar precio solo dentro de la ficha
