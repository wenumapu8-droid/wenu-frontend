## El Código Cosmogónico del Retorno — la fórmula-madre

`Ω → Δ → O → Γ → M → C → W → R → Ω′`

- **Ω** potencial indiferenciado · **Δ** diferenciación · **O** centro/semilla ·
  **Γ** despliegue · **M** multiplicidad · **C** organización · **W** mundo
  habitable · **R** disolución/catástrofe/retorno · **Ω′** nuevo potencial CON MEMORIA.
- Mapea directo a **−∞ → 0 → +∞ → −∞′**. La prima (′) = el retorno no repite el
  comienzo: incorpora historia, pérdida, transformación. (= la doble espiral / hélice.)

### Teorema cosmogónico KODEX
Todo mundo surge cuando una diferencia organiza el potencial; todo retorno
transforma el potencial mediante memoria.
**Ω′ = R[W(Γ(O(Δ(Ω))))], Ω′ ≠ Ω**
(Es lógica narrativa/generativa, no ley física. Es la que convierte investigación
en artefacto, experiencia y archivo — hermana de K(n+1)=(R∘M∘T∘E)(K(n)).)

## Las 6 reglas de traducción responsable (ética Hidden Sky, del propio Atlas)

1. **Citar procedencia** (pueblo, región, fuente, condición documental).
2. **Separar estructura y símbolo** (estudiar la operación, NO copiar iconografía sagrada).
3. **Distinguir tradición viva y archivo antiguo.**
4. **No universalizar** (analogías comparativas, no doctrina secreta única).
5. **Diseñar una gramática propia** — punto, círculo, eje, espiral, umbral, trama,
   secuencia. → **valida los sigilos KODEX: son exactamente esto.**
6. **Hacer visible el proceso** — cada artefacto muestra investigación, traducción,
   prototipo, función y límites. → **el machine-language en pantalla ES esto.**
