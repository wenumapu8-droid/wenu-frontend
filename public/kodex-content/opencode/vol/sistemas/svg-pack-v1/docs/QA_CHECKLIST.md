# KODEX QA Checklist

## Visual hierarchy

- [ ] One dominant anchor.
- [ ] Headline readable in under three seconds.
- [ ] No equal-intensity full-screen tint.
- [ ] Dark field remains 70–85%.
- [ ] Accent coverage remains within scene token range.
- [ ] No more than two active signal colors.
- [ ] One primary CTA.

## Typography

- [ ] Display uses technical sans/condensed stack.
- [ ] Data uses mono.
- [ ] Supporting copy is short.
- [ ] Body copy never overlaps the visual anchor.
- [ ] Labels preserve minimum mobile size.
- [ ] No more than three type families.

## Motion

- [ ] Approximately 70% slow, 20% medium, 10% fast.
- [ ] Glitch is event-driven.
- [ ] Maximum two high-priority motions.
- [ ] Pointer displacement is capped.
- [ ] Audio is smoothed.
- [ ] Reduced motion is readable and complete.

## Performance

- [ ] One active canvas.
- [ ] Desktop target 60 FPS.
- [ ] Mobile minimum target 45 FPS.
- [ ] DPR capped.
- [ ] Canvas paused when hidden.
- [ ] WebGL resources disposed.
- [ ] No memory growth after ten scene cycles.

## Responsive

- [ ] 390×844.
- [ ] 430×932.
- [ ] 768×1024.
- [ ] 1440×900.
- [ ] 1920×1080.
- [ ] No vertical scroll.
- [ ] CTA always visible.

## Source distance

- [ ] No literal source image.
- [ ] No copied slogan.
- [ ] No copied symbol.
- [ ] No copied lettering.
- [ ] Structural similarity remains abstract.
