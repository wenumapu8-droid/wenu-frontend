# KodeLife Presets

These shaders are original KODEX starter shaders.

Expected uniforms:

```glsl
uniform float time;
uniform vec2 resolution;
uniform vec2 pointer;
```

In KodeLife, create/map uniforms with those names. If your project uses
different names, rename them in the shader or map them in the stage settings.

Files:

- `liquid-acid-kodelife.frag`
- `mandelbrot-kodelife.frag`
- `archive-orbit-kodelife.frag`

The web runtime versions use GLSL ES 3.00 and additional textures/uniforms.
