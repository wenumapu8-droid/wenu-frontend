# Uso, derechos y atribución

## Por qué el ZIP no incluye 300 archivos descargados

Los Términos de usuario de GIPHY prohíben el scraping automatizado y restringen copiar, distribuir o explotar comercialmente contenido sin permisos. Por eso este kit no raspa la web ni redistribuye una biblioteca de archivos ajenos.

## Integración oficial

La API requiere una API key. Las claves beta están limitadas y las búsquedas deben respetar los límites de uso.

GIPHY exige:

- Mostrar de forma visible `Powered by GIPHY`.
- Mantener atribución del creador o la fuente cuando esté disponible.
- No modificar ni quitar parámetros de las URLs devueltas por la API.
- No cachear copias o URLs de medios salvo aprobación explícita.
- Revisar derechos si el uso será comercial, publicitario, de producto o merchandising.

## Recomendación para KODEX

GIPHY sirve para descubrir y prototipar capas efímeras. Los símbolos centrales, sellos, portales, loaders, barcodes y fenómenos hero de KODEX deberían terminar siendo activos originales propios: SVG, shader, sprite o animación procedural. Así la identidad no depende de una biblioteca externa ni de licencias variables.
