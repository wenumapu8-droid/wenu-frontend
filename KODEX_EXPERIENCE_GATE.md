# KODEX−∞ EXPERIENCE GATE

Status: ACTIVE production-convergence governance. This file does not create a new renderer/router/state authority. It converts existing KODEX canon, Deep Navigation, Motion Engine, Page Mockups, wireframes, creator review and browser evidence requirements into one mandatory scene-acceptance gate.

## 0 — Core product truth

KODEX is not a collection of pages, posters or dashboards. It is one living interactive world undergoing seven transformations:

THRESHOLD → PROLOGUE → DESCENT → ARCHIVE → MACHINE → COSMOLOGY → RETURN

Perceptual priority:

ART / ORGANISM → SIGNAL → MOTION → TITLE → INTERACTION → DEPTH → SYSTEM

Core traversal law:

ANCHOR → FIELD RESPONSE → STATE PRESSURE → CONVERGENCE → CROSSING → CONTINUITY → MEMORY RESIDUE

A route change is implementation detail. The visitor must perceive state + depth transformation.

## 1 — One grammar, seven worlds

Shared grammar may include navigation reliability, journey persistence, accessibility, reduced motion, control states, evidence capture, KDX.TYPE interface and micrographic truth rules.

Each scene MUST still own a distinct:

- dominant organism / phenomenon
- macro silhouette
- material world
- scene verb
- color behavior
- type behavior
- motion behavior
- interaction semantics
- micrographic vocabulary
- depth-transition behavior

FAIL if scenes read as seven skins of one template.

## 2 — Scene contracts

### THRESHOLD
Verb: ENTER / CONSENT / INVOKE
Dominant organism: red-black aperture / gate / ritual threshold
Required consequence: entry choice visibly changes field and opens the journey
Forbidden result: static poster + ENTER button

### PROLOGUE
Verb: OBSERVE / ACQUIRE / LOCK
Dominant organism: observation eye / violet signal field
Required causal states: DORMANT → AWARE → LOCK → TRACK → INSPECT → DESCEND
Required consequence: eye, title, signal and micrographics tell the same state truth
Forbidden result: eye animation disconnected from title/readouts

### DESCENT
Verb: CHOOSE / DESCEND / ABSORB
Dominant organism: depth field / strata / vortex / compression axis
Required consequence: selection creates visible pressure, deformation and inward traversal
Forbidden result: orange poster + DESCEND CTA with no depth behavior

### ARCHIVE
Verb: REMEMBER / RETRIEVE / RELATE
Dominant organism: living specimen / memory field
Required consequence: opening a specimen reveals provenance, genealogy or relation progressively
Forbidden result: generic modal/card gallery disconnected from the world

### MACHINE
Verb: PROCESS / TRANSFORM / GENERATE
Dominant organism: causal computational mechanism
Required consequence: real parameter/action visibly changes output
Forbidden result: fake telemetry or GENERATE button with decorative response

### COSMOLOGY
Verb: CONNECT / MAP / ORBIT
Dominant organism: relational field / orbital system
Required consequence: REVEAL CONNECTION exposes a real relation/state change
Forbidden result: static cosmic infographic + magenta CTA

### RETURN
Verb: REINTEGRATE / RECALL / RETURN
Dominant organism: recomposition / residue / restored pattern
Required consequence: explicit journey facts/residues influence the return state
Forbidden result: static editorial end card or reset

## 3 — Mandatory scene anatomy

Every scene must communicate, in its own composition:

1. scene identity / state
2. dominant organism
3. primary statement / KDX.TYPE behavior
4. truthful supporting signal/micrographics
5. one meaningful primary action
6. one secondary reveal/inspection path when relevant
7. onward/back/index navigation

The order may be spatial on desktop and temporal on mobile. Do not force identical layout geometry.

## 4 — Mobile law

NO RESPONSIVE LAYOUT AS SHRINKING.
RESPONSIVE CAMERA + RESPONSIVE CHOREOGRAPHY.

Desktop = spatial / simultaneous.
Mobile = temporal / progressive.

Preserve on both:

- organism dominance
- macro silhouette
- hierarchy
- type identity
- atmosphere
- geometry / void relationship
- interaction meaning

Hard FAIL on mobile if:

- desktop plate is scaled/cropped to fit
- primary type overlaps or becomes illegible
- CTA competes with organism
- navigation blocks scene content
- excessive dead space destroys temporal rhythm
- micrographics become meaningless miniatures

Required evidence sizes: 390×844 and 412×915.

## 5 — Glitch / signal law

KODEX may feel like a rupture in computational reality, but glitch is causal language, not decoration.

Permitted grammar includes, when semantically appropriate:

- scanlines / raster cadence
- controlled RGB misregistration
- ASCII / glyph fields
- line-relief / displacement fields
- signal bands
- feedback / wave distortion
- contact halo / lensing
- state-driven noise/flicker
- dynamic type ghosting / scan / focus

A glitch event must map to at least one real condition:

STATE CHANGE / INPUT / SIGNAL / DEPTH / MEMORY / TRANSITION

Hard FAIL if glitch is always-on visual garnish with no semantic cause.

Do not apply CRT/ASCII/shaders identically to every scene.

## 6 — KDX.TYPE law

Titles are part of scene behavior, not static labels.

Expected behavioral families:

- THRESHOLD: breath / aperture / compression
- PROLOGUE: scan / acquisition / tracking
- DESCENT: perspective / recession / pressure
- ARCHIVE: coordinate / genealogy / assembly
- MACHINE: modular assembly / decomposition
- COSMOLOGY: orbit / field relation
- RETURN: dissolve / seed / reconstitution

A title may stabilize in some states, but state awareness must remain demonstrable somewhere in its behavior. Do not add gratuitous motion merely to satisfy the gate.

## 7 — Micrographic / data truth

Every readout that looks live must have:

NAME | SOURCE | CLASS | STATE DEPENDENCY | VISIBLE RESPONSE

Allowed classes:

- LIVE
- DERIVED
- CANONICAL_PARAMETER
- EDITORIAL
- DECORATIVE (must not masquerade as measurement)

Remove invented RA/DEC, scientific-looking coordinates, signal numbers or telemetry when no real source/derivation exists.

## 8 — Control grammar

PREVIOUS / NEXT-or-scene-action / INDEX / INSPECT / AUDIO and scene-specific actions must share one coherent interaction grammar while respecting scene identity.

Required states where applicable:

idle / hover / focus-visible / pressed / active / disabled / touch

Controls remain subordinate to organism. Minimum touch targets must remain usable. Invisible overlays must not block input.

## 9 — Motion law

Motion must communicate:

- state
- causality
- depth
- relation
- memory
- atmosphere

Do not animate every layer equally.
Do not use constant maximal glitch.
Do not use generic particles by default.

Scene transition must preserve a perceptual anchor or residue whenever possible. Nothing important should simply disappear without transforming.

## 10 — Reference-first fidelity

Before changing any scene:

REFERENCE → WIREFRAME → CURRENT RUNTIME → CLASSIFY → CHANGE

Classify current implementation:

KEEP / REFINE_TO_REFERENCE / MISSING

Only MISSING authorizes genuinely new composition without a governed visual anchor.

Fidelity comparison is SAME REGION / SAME FUNCTION, not whole-image histogram similarity.

Compare:

- organism ↔ organism
- title ↔ title
- state color ↔ state color
- micrographics ↔ micrographics
- control ↔ control
- macro hierarchy ↔ macro hierarchy
- motion function ↔ motion function

## 11 — Hard visual FAIL conditions

A scene cannot be REPLICATION_READY / RELEASE_READY if any of these remain materially true:

- POSTER + BUTTON
- STATIC MOCKUP EMBEDDED AS WORLD
- GENERIC DASHBOARD / HUD DOMINANCE
- ORGANISM NOT DOMINANT
- DESKTOP SHRUNK INTO MOBILE
- NORMAL PAGE SWAP WITH NO DEPTH CONTINUITY
- FAKE LIVE DATA
- DECORATIVE GLITCH WITH NO CAUSE
- TITLE DISCONNECTED FROM SCENE STATE
- PRIMARY ACTION WITH NO VISIBLE CONSEQUENCE
- MODAL / PANEL THAT BREAKS IMMERSION WITHOUT NECESSITY
- SCENE NOT RECOGNIZABLE WHEN MOST COPY IS HIDDEN

## 12 — Browser evidence gate

A build/CI PASS is not visual closure.

Every scene-changing candidate must provide evidence tied to ONE exact SHA:

- branch
- exact SHA
- noindex preview or local real-browser proof
- desktop 1440 capture
- mobile 390×844 capture
- mobile 412×915 capture
- reduced-motion capture where relevant
- interaction proof/video
- navigation proof
- console/runtime result
- reference used
- same-region semantic comparison
- P0 defects
- P1 defects

Allowed working statuses:

PREVIEW_READY / REFINE / BLOCKED / PROVISIONAL_KEEP

Do not write DONE solely from terminal/build evidence.
