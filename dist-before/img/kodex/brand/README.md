# KODEX-∞ Master Seal

Included files:

- `KODEX_Master_Seal_transparent.png`
  Transparent PNG, 1024×1024.

- `KODEX_Master_Seal_vector_trace.svg`
  True multi-tone vector trace. Best for large-format editing and recoloring.
  It contains many paths because it preserves the engraved detail.

- `KODEX_Master_Seal_web_optimized.svg`
  Reduced vector version for interfaces, loaders, seals and motion.
  Smaller and easier to animate than the detailed trace.

- `KODEX_Master_Seal_high_fidelity.svg`
  SVG container with the transparent PNG embedded.
  Highest visual fidelity, but the artwork inside remains raster.

Recommended use:
- Website hero / exact appearance: high-fidelity SVG or transparent PNG.
- SVG animation / CSS stroke effects: web-optimized SVG.
- Editing in Illustrator, Figma or Inkscape: vector trace SVG.

The auto-vector trace may require small manual cleanup before metal cutting,
laser engraving, embroidery or trademark master production.
