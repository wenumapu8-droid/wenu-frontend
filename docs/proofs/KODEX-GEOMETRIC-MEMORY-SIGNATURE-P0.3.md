## Thesis under test

A visitor route can become a visible geometric memory artifact **without creating a second memory system**.

Bounded chain:

`existing routeTrace → existing Memory Constellation → deterministic Geometric Memory Signature → internal SVG manifestation`

The SVG is a projection of recorded route memory. It is not a route authority, user score, psychological profile, spiritual diagnosis or hidden-topology map.

## What P0.3 derives

Only existing observed facts are admitted:

- visited nodes;
- observed traversal edges;
- total visits and revisits;
- observed branch points;
- returns to already visited nodes;
- distinct visited fields;
- current route depth;
- current route signature.

No unvisited node or candidate route enters the signature.

## Bounded topology vocabulary

- `SEED_POINT` — one known node;
- `PATH` — bounded route with no return/branch and low depth;
- `SPIRAL_DESCENT` — deeper unique traversal represented through finite nested/spiral spacing;
- `BRANCH_TREE` — observed divergence without a closed return;
- `ORBIT_LOOP` — route returns to an already visited node;
- `CONSTELLATION` — unique route spans at least three observed semantic fields;
- `HYBRID_WEAVE` — return/revisit plus observed divergent exits.

These names are descriptive KODEX render grammars. They are not claims that human cognition or natural systems literally follow one universal geometry.
