## Interaction grammar

- pointer/touch drag rotates the instrument;
- release velocity produces bounded inertial motion;
- the three rings rotate at different signed ratios so new alignments emerge from one input;
- high input velocity can enter `ANOMALY`;
- `ANOMALY` fractures presentation only — no source data, route state or memory is destroyed;
- `RETURN / REASSEMBLE` restores the visual instrument;
- left/right keyboard arrows rotate;
- `R` performs RETURN when fractured;
- `ENTER` opens the currently aligned existing KODEX scene;
- reduced-motion disables inertial fracture behavior and keeps direct manipulation bounded.
