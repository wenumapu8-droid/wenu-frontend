## 3. KODEX−∞ — core concept

KODEX is a **living codex / visual operating system**, not a conventional scrolling marketing site.

Core qualities:

- fullscreen or scene-based experiential navigation;
- each scene may behave like a techno flyer, archive specimen, ritual device or scientific instrument;
- interaction should reveal relationships, memory and state rather than merely decorate the page;
- visual systems can breathe, mutate, observe, respond, resonate and remember;
- procedural Canvas/SVG/WebGL/GLSL are preferred when they add meaning;
- every ambitious visual should have a fallback/reduced-motion path;
- source artwork should be preserved when a plate has creator approval; prefer **plate-to-live** augmentation over redrawing approved work from prose;
- public claims must distinguish evidence, interpretation, testimony, speculation and mythopoetic framing.

### Canonical seven-scene journey

1. **THRESHOLD** — invitation, scope, voluntary entry, orientation.
2. **PROLOGUE** — context and central question.
3. **DESCENT** — evidence, complexity and exploration.
4. **ARCHIVE** — entities, records, relations and provenance.
5. **MACHINE** — method, transformation, algorithms and generative logic.
6. **COSMOLOGY** — synthesis across scales and systems.
7. **RETURN** — integration, interpretation, memory and next action.

Canonical CTA vocabulary may include:

- ENTER THRESHOLD
- BEGIN TRANSMISSION
- DESCEND FURTHER
- OPEN ARCHIVE
- RUN PROTOCOL
- MAP THE FIELD
- RETURN WITH MEMORY

Projects may use fewer scenes, but the missing functions must be accounted for intentionally.

### Important KODEX motifs / domains

Use as concept families, not mandatory decoration:

- eye / observation network;
- spiral / DNA / ascent;
- black sun / source / void;
- portal / threshold / wormhole metaphor;
- pulse / heart / coherence;
- tree / roots / Gaia / growth;
- skull / specimen / anatomy;
- planetary/orbital systems;
- archive, dossier, barcode, coordinate and telemetry language;
- water and micro↔macro structure;
- alchemy and transformation;
- Jungian archetypes / synchronicity / Red Book as interpretive material;
- altered-state imagery and DMT-temple aesthetics as subjective/visionary language;
- ancestral cosmologies and Indigenous knowledge only with provenance and cultural gate;
- UFO/contact/disclosure topics as testimony/speculation unless supported by stronger evidence;
- scientific models such as quantum mechanics, black holes, string theory, holography or simulation must not be flattened into proof of spiritual claims.

### Epistemic contract

Every factual or explanatory KODEX claim should have an explicit truth class when material. Preferred vocabulary includes:

- OBSERVED
- DERIVED
- ESTIMATED
- PROXY
- INTERPRETATION
- TESTIMONY
- SPECULATION
- MYTHOPOETIC
- SYNTHETIC
- UNKNOWN

Metaphor is allowed. Mislabelled metaphor is not.

### Cultural gate

When Indigenous, ancestral, sacred or community-held knowledge is involved:

- preserve source, author/community and provenance;
- distinguish inspiration from authorized representation;
- never fabricate “tribal-style” symbols as generic decoration;
- identify permission/authority needs before open publication;
- maintain attribution and the ability to correct/remove material;
- aesthetic ambition never overrides cultural authority.

## 4. KODEX visual grammar

KODEX should feel authored, not like a generic AI sci-fi dashboard.

### Hierarchy

Use one dominant visual proposition per scene. Dense information may orbit it, but the visitor must understand the primary signal immediately.

### Color

Default principle: one dominant neutral field plus a restrained number of signal colors. Saturation is scarce and meaningful. Scene-specific exceptions are allowed when canon/approved plate requires them.

### Typography

- Display: decisive scene identity / proposition.
- Mono: provenance, coordinates, telemetry, legends and code.
- UI sans: controls, explanations and operational text.

Large type must support hierarchy, not compensate for weak content.

### Spatial modes

Rotate intentionally among radial, orbital, dendritic, topographic, reticular, sequential, cartographic, volumetric, typographic and field-based compositions. Do not turn every page into a centered mandala.

### Motion grammar

Motion should communicate state, causality, energy, relation or memory. Prefer:

- breathe;
- orbit;
- scan;
- reveal;
- resonate;
- charge;
- transmit;
- mutate;
- settle;
- remember.

Respect `prefers-reduced-motion`, hidden-tab pause and performance budgets. Navigation state must not live only inside a shader.

### Interaction

Pointer/touch behavior must have a readable consequence. Avoid meaningless parallax and “interactive” effects that hide essential information.

- Astro SSG;
- HTML/CSS/JavaScript/TypeScript;
- SVG / Canvas2D;

KODEX code currently lives across `src/kodex/`, `src/lib/kodex/`, KODEX routes, data and experimental lab paths depending on branch.

Engineering principles:

- preserve approved assets and provenance;
- no framework churn without a strong reason;
- use real mobile viewport evidence;
- test reduced motion and keyboard/touch behavior;
- keep simulated telemetry labelled as simulation;
- separate visual renderer from routing/history/state ownership;
- pause expensive loops when hidden/out of view;
- cap DPR or complexity on mobile where needed;
- document performance and fallback behavior.

## 6. WËNU MAPU — brand system

WËNU MAPU is an independent body-jewelry / piercing / design brand. Its direction is **dark, premium, editorial, neo-ancestral and precise** — not generic boho, generic New Age or invented tribal aesthetics.

The product and the story must remain credible enough for real commerce.

### Brand pillars

- body as chosen territory / identity;
- jewelry as declaration, not disposable decoration;
- materials with traceable origin and material reality;
- geometry, nature, astronomy and memory;
- ritual framing without making false metaphysical or medical claims;
- slow, intentional, distinctive pieces over anonymous mass-market presentation;
- strong macro/product photography and material detail;
- respectful cultural sourcing and attribution.

### Product reality

WËNU MAPU spans body jewelry and related objects such as piercing jewelry, hangers, ear weights, amulets and ritual pieces. Product information must prioritize factual material, fit, size, wearability, care and stock reality.

Known professional material language includes implant-grade titanium ASTM F-136 and 14k gold where applicable. Never upgrade a product material claim without verified source data.

### Web / commerce principles

- Home must explain what WËNU MAPU is quickly enough for a first-time visitor.
- Product imagery must show material and detail clearly.
- WooCommerce is the product data source in the current Astro architecture.
- No silent empty-catalog builds.
- SEO/structured data should reflect real products and pages.
- Mobile experience is first-class.
- Scarcity messaging must come from actual scarcity, not fabricated urgency.
- Customer education and safety information should be clear, practical and separated from poetic copy.

### Voice

WËNU MAPU may be intimate, ritual, poetic and cosmic, but never vague at the expense of product truth. Good brand language can coexist with exact specifications.

## 11. Definition of done

A KODEX or WËNU MAPU task is not done because code/assets exist.

Minimum completion requires, as applicable:

- intended implementation exists;
- build/tests/checks pass or blockers are truthfully documented;
- browser/visual evidence exists for visual work;
- desktop + relevant mobile states are checked;
- no essential accessibility regression;
- factual/provenance claims are traceable;
- approved visual/source fidelity is respected;
- no unapproved deployment occurred;
- `CURRENT_STATE.md` / `LEARNINGS.md` updated when the result changes durable project knowledge.

A KODEX visualization is ready only when it is traceable, legible, coherent with the graph/scene system, accessible in a non-animated/non-visual form where needed, culturally safe, performant on the target and reproducible/versioned.
