> Entonces ya encontramos el error de dirección y también la solución.
>
> No necesitamos rehacer KODEX. Necesitamos **recomponer lo muchísimo que ya
> existe bajo una sola dirección de experiencia**.

## LA REGLA DE PRODUCCIÓN

> **ESCONDER EL SISTEMA. MOSTRAR EL UNIVERSO.**

Los layers, rutas, memoria, contratos, estados, fuentes y demás siguen
funcionando debajo. **No los borramos.** Pero dejan de convertirse
automáticamente en cajas, menús, botones y texto visible.

La capa que recibe el huésped pasa a ser principalmente:
**arte + movimiento + profundidad + sonido + tipografía + interacción.**

## LA CORRECCIÓN GLOBAL: REFINE, NO REJECT

> PROLOGUE, DESCENT, ARCHIVE, HEART, etc. contienen muchísimo material bueno.
> **El problema es que la interfaz se puso encima del material.**

## EL VIAJE, RECOMPUESTO

    THRESHOLD  = entrar por primera vez al agujero
    PROLOGUE   = algo empieza a observar / responder
    DESCENT    = caer físicamente hacia capas interiores
    ARCHIVE    = descubrir conocimiento como espacios / constelaciones,
                 NO como tarjetas
    MACHINE    = ver estructuras generándose y transformándose
    COSMOLOGY  = expansión brutal de escala
    RETURN     = las dimensiones recorridas convergen
    HEART      = cuando aparezca: orientación, respiración y memoria visual.
                 No dashboard.

## ENTRE ESCENAS

No quiero sentir:

    NEXT →

Quiero sentir:

    algo aparece → me atrae → lo toco → el espacio reacciona →
    atravieso → estoy en otro lugar.

Incluso los botones que técnicamente necesitamos pueden convertirse visualmente
en **hotspots, anomalías, símbolos, objetos, grietas, nodos o zonas vivas**.
La accesibilidad sigue existiendo debajo.

## LA REGLA DURÍSIMA DE LAS OBRAS

> **NUNCA deformar una imagen para hacerla caber.**

Si una obra no cabe, movemos la cámara: pan, zoom, framing, máscara,
profundidad, aparición parcial. **La obra conserva su proporción.**

## QUÉ HARÍA AHORA — EL PRIMER ENTREGABLE

> Primero arreglaría **el comienzo completo** antes de seguir decorando
> habitaciones posteriores. Si los primeros 20–30 segundos no se sienten KODEX,
> todo lo maravilloso que venga después llega demasiado tarde.

El primer entregable exigido:

    THRESHOLD → PORTAL → PROLOGUE → primera profundidad de DESCENT

como **una experiencia audiovisual continua en móvil, sin apariencia de
dashboard**.

Una vez que ese pequeño viaje diga «AHHHH, ESTO ES KODEX», eso se convierte en
la **gramática de producción** para el resto del universo. Y entonces sí:
recuperamos todo lo avanzado, pero colocado correctamente.

> No necesitamos más piezas. Necesitamos dirigir la película.
