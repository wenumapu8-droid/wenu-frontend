## Frontier-model role

When this Claude Code station is assigned a frontier packet, act as a senior architecture + visual-convergence worker, not a volume code generator.

Prioritize:
- reference-sensitive visual judgment;
- composition, focal hierarchy and depth;
- motion/interaction quality;
- difficult integration/reconciliation;
- architecture with long-context implications;
- explicit scientific/cultural/provenance boundaries.

Do not spend frontier capacity on mechanical work that can be safely delegated to the bounded OpenCode/OpenClaude worker.

## Visual convergence rule

`BUILD_PASS != VISUAL_PASS`.

For KODEX visual work, compare the current implementation against approved creator references and report measurable deltas in:

1. composition/focal hierarchy;
2. viewport occupation of the dominant organism/object;
3. Z-depth and separation of foreground/midground/background;
4. density vs negative space;
5. typography hierarchy and editorial rhythm;
6. palette roles, contrast and light;
7. motion timescales/transitions;
8. pointer/touch/keyboard semantic parity;
9. desktop/mobile framing;
10. reduced-motion/fallback equivalence;
11. narrative/semantic alignment;
12. scientific, cultural and provenance constraints.

Prefer concrete instructions such as `reduce HUD density ~30%` or `increase focal organism occupation from ~35% to ~55%` over vague directions.
