## LAS DOS REGLAS CANÓNICAS

> **En KODEX, cada elemento visible puede ser simultáneamente imagen,
> información, instrumento, nodo y portal. Su función cambia según profundidad,
> contexto y memoria del observador.**

> **KODEX no navega principalmente entre páginas. Navega entre estados de
> significado.**

---

## 1 · EL ERROR QUE SE ESTABA COMETIENDO

KODEX no debe funcionar como una colección de páginas bonitas conectadas por
navegación tradicional. Las siete escenas son solamente **macroestados del
viaje**. Dentro de cada una existe profundidad, ramificación, memoria y
adaptación.

## 2 · EL ORDEN DE LA EXPERIENCIA

1. **Entrada — OCÍN / materia visual.** El usuario no entra leyendo una
   enciclopedia. Entra por el universo visual: composiciones limpias,
   fragmentos de obra, texturas, fotografías, símbolos, collage editorial.
   Mucho espacio negativo. Pocas instrucciones. *El arte es la puerta
   sensorial.*
2. **Activación.** Al interactuar, la composición se carga: láminas, diagramas,
   infografías, microdatos, palabras flotantes, copy glitch, traducciones
   simultáneas, símbolos, números, títulos cinéticos, telemetría, QR. *Ya no
   parece una galería: parece que el usuario encendió una máquina.*
3. **Instrumentación — la cabina alrededor del núcleo.** FILTER / TRACE /
   SIGNAL / MEMORY / SCALE / MATERIAL / ORIGIN / TIME / BODY / COSMOS. **No son
   decoración sci-fi:** cada control modifica el objeto central o la forma de
   interpretar el contenido. Una fotografía puede tener RAW → DITHER → THERMAL
   → EDGE → TOPOLOGY → SIGNAL → MEMORY, y cada modo revela información
   distinta.
4. **Profundización.** Un click no siempre significa "ir a otra página". Puede
   significar **acercarse**.

   | gesto | significado |
   |---|---|
   | click | activa |
   | segundo click | abre contexto |
   | doble click | profundiza |
   | click sostenido / long press | entra dentro |
   | drag | altera |
   | hover | detecta |
   | scroll / gesto local | cambia escala |
   | back | vuelve al nivel anterior |

   `IMAGEN → FORMA → SÍMBOLO → CONCEPTO → RELACIONES → ORIGEN → NÚCLEO`

   Y el núcleo puede ser completamente distinto según el concepto. Microscopía
   conceptual.

**Ejemplo ÁRBOL.** No aparece un menú con "raíces / hojas / fotosíntesis". Se
explora el árbol. Raíz → suelo → micelio → redes → simbiosis → comunicación →
memoria. Hoja → luz → fotosíntesis → pigmento → energía → transformación.
Ramificación → fractal → crecimiento → redes → río → pulmón → neurona.
*El objeto es simultáneamente interfaz e información.*

**Ejemplo CORAZÓN.** Se empieza en una obra donde apenas hay un elemento rojo.
Se toca. Aparecen más señales rojas. rojo → pulso → ritmo → circulación →
corazón → cuerpo → memoria → emoción → señal. Al llegar no debe parecer "otra
página": tiene que sentirse como **encontré algo oculto dentro del KODEX**.

## 3 · KODEX APRENDE EL RECORRIDO

No se le pregunta al visitante qué le interesa. Sus acciones lo dicen. Quien
toca verde, raíces, organismos, micelio, agua, materia, crecimiento construye
`BIOLOGY ↑ NETWORKS ↑ NATURE ↑ GROWTH ↑ ECOLOGY ↑`. Quien toca estrellas,
agujeros negros, geometría, tiempo, anomalías, infinito construye `COSMOLOGY ↑
GEOMETRY ↑ TIME ↑ PHYSICS ↑ ANOMALY ↑`.

No cambia el contenido verdadero: **cambia la ruta hacia él**.

La navegación es una red de significado, no `HOME / ABOUT / GALLERY / NEXT`:

```
                MEMORIA
                   │
CUERPO ────── CORAZÓN ────── RITMO
 │               │             │
SANGRE         PULSO       FRECUENCIA
                 │
               SEÑAL
                 │
              MÁQUINA
```

Una cosa puede pertenecer a múltiples relaciones. Por eso una imagen, palabra,
símbolo o gráfico puede ser portal hacia distintas ramas.

## 4 · LAS SIETE ESCENAS SON ESTADOS, NO PÁGINAS

- **THRESHOLD** — primera percepción. Arte, silencio, señal mínima.
- **PROLOGUE** — el sistema empieza a hablar.
- **DESCENT** — se entra dentro de las cosas. Zoom conceptual, capas.
- **ARCHIVE** — el conocimiento se estructura. Láminas, documentos, memoria.
- **MACHINE** — se puede manipular. Filtros, shaders, parámetros, organismos.
- **COSMOLOGY** — las conexiones locales se vuelven grandes redes.
- **RETURN** — el sistema devuelve tu recorrido. No se vuelve exactamente al
  principio: KODEX recuerda lo que observaste.

## 6 · LAS LÁMINAS SON EL GENOMA, NO EL RESULTADO

> **Las láminas no son el resultado final de KODEX. Son fósiles completos de su
> lenguaje que podemos descomponer para descubrir las reglas que las
> produjeron.**

Las ~32 láminas no son 32 páginas: son **32 fuentes madre**. Una sola contiene
composición, fotografía, organismo central, retícula, título, tipografía,
bloque editorial, código, línea, textura, símbolo, gráfica, microinterfaz,
relación espacial, tratamiento cromático y animación potencial.

```
LÁMINA ORIGINAL → DESCOMPOSICIÓN → GRAMÁTICA KODEX → RECOMBINACIÓN SEGÚN CONTEXTO
      IMAGEN · TIPOGRAFÍA · DIAGRAMA · SÍMBOLO · TEXTURA · GRID
      COPY   · DATOS      · CONTROL  · COLOR   · MOVIMIENTO · RELACIÓN
```

Una gráfica que estaba junto a un corazón puede reaparecer alrededor de una
estrella. Una textura de organismo puede volverse máscara de una fotografía. Un
cuadro puede aparecer completo y, cinco niveles más abajo, volver convertido en
píxeles, espectro, mapa de bordes o estructura geométrica. **Todo se siente
emparentado porque está construido con el mismo ADN.**

### La base estable

```
KODEX−∞
   ├── CANON (lenguaje / reglas)      ← permanece estable
   └── CONTENT (temas / conceptos)
            │
        VISUAL DNA — las láminas existentes
            │
        DESCOMPOSICIÓN
            │
   ATOMS        PATTERNS      BEHAVIORS
   imagen       grid          glitch
   texto        layout        reveal
   glyph        ratios        pulse
   gráfico      density       zoom
   textura      rhythm        mutate
            │
        ASSEMBLY SYSTEM → cada nodo/concepto
            │
   PROFUNDIDAD → MEMORIA → RETORNO       ← crece indefinidamente
```

Mañana se agregan 100 imágenes, 20 conceptos, otra lámina o nuevos shaders y
**no hay que rediseñar KODEX: se alimenta el sistema.** Conecta con el Asset
Atlas ya definido — familia, función, escena posible, formato y uso — en vez de
tratar cada imagen como pieza aislada.

### Cada tema se compone con el mismo vocabulario

```
concept: HEART                     concept: TREE
semantic:  body pulse rhythm       semantic:  growth root branch
           blood memory signal                network soil memory
visual:    red organic radial      visual:    green brown branching
           vascular pulse                     organic
behaviors: pulse expand scan       behaviors: grow branch trace
           depth                              descend
```

**La gramática permanece. La manifestación cambia.**

### Profundidad dentro de una lámina

```
Nivel 0  la lámina completa
Nivel 1  se toca una zona → la lámina se recompone y aísla ese fragmento
Nivel 2  el fragmento ocupa el centro y aparecen sus datos
Nivel 3  el arte desaparece parcialmente y deja ver su estructura
Nivel 4  se entra en sus relaciones semánticas
Nivel 5  aparece otra obra que comparte una relación oculta
```

Una lámina puede contener 10–30 interacciones, 20 conceptos, 50 relaciones y
varias rutas. Por 32 láminas: **centenares o miles de estados de experiencia
sin crear a mano centenares de páginas.**

### Esto resuelve la coherencia

El peligro era `tema A → diseño A`, `tema B → diseño B`… y después de 200 temas,
un Frankenstein. Con la gramática, HEART, TREE y COSMOS son variantes distintas
que pertenecen inequívocamente al mismo organismo. Como en la naturaleza: una
neurona, una raíz, un río y un rayo son distintos y comparten el mismo patrón
de ramificación.

### Versiones, no reemplazos

`KDX VISUAL DNA v1 → v1.1 → v1.2 → v2`, conservando versiones y marcando lo
reemplazado en vez de borrarlo, según la política de trazabilidad ya definida.
KODEX evoluciona sin perder el viaje anterior.

## QUÉ SIGNIFICA ESTO PARA LO QUE HAY HOY

Anotado por el agente, no por el creador, para no confundir canon con lectura:

- **Ya tenemos mucho más KODEX construido de lo que parece.** El trabajo no es
  inventar 500 pantallas: es convertir lo hecho en un sistema compositivo vivo.
- El corredor de siete escenas **no se tira**: pasa de ser el producto a ser la
  capa de macroestados sobre la que corre el sistema.
- Lo que falta no es diseño, es **gramática + descomposición + ensamblaje**:
  KDX.GRAPH (nodos y relaciones) y el Node Manifestation Renderer (cómo un nodo
  se convierte en pantalla) ya nombrados en el documento 12.
- Regla de aceptación derivada: **si una pantalla se puede describir como
  "tarjetas con datos", no es KODEX.** Cada elemento tiene que poder responder
  qué es como imagen, como información, como instrumento, como nodo y como
  portal.
