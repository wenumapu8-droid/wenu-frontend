# KODEX−∞ — Monochrome / Signal Color Grammar

Status: **HIGH-LEVEL DIRECTION CANONICAL / NUMERIC DISTRIBUTION NOT YET CANONICAL**

## Canonical rule

KODEX uses a predominantly monochrome visual field with selective color appearing as **signal, state, rupture, transition or semantic emphasis** rather than continuous decoration.

In shorthand:

`MONOCHROME BASE + COLOR AS EVENT`

This direction is compatible with heterogeneous screens: some may be almost completely black/white, others may contain one controlled color family, and a minority may become intensely chromatic where the narrative state warrants it.

## What remains immutable

Ocín artwork is not recolored merely to force it into this grammar.

The KODEX interface adapts around authored work through:
- frame;
- scale/crop only when permitted;
- typography;
- metadata;
- spatial hierarchy;
- signal overlays;
- motion;
- state transitions.

The artwork remains the source object. KODEX is the editorial/runtime system around it.

## Three operational modes

### M0 — MONO

Use when restraint, threshold, archive authority, silence, origin or return-to-zero matter more than spectacle.

Typical behavior:
- black / white / gray / paper;
- high contrast or deliberately quiet contrast;
- no decorative RGB noise;
- material and typography carry hierarchy.

### M1 — SIGNAL COLOR

One bounded color family behaves as system state.

Examples of roles, not fixed palette assignments:
- active state;
- route emphasis;
- selected node;
- anomaly;
- memory trace;
- portal/open condition;
- warning or irreversible action.

Meaning may never depend on hue alone.

### M2 — COLOR EVENT

A rare scene-level chromatic rupture.

Use when color is itself part of the narrative transformation rather than a skin. It should read as an event because the surrounding system is more restrained.

## Working quantitative hypothesis — INFERRED, NOT CANON

For collection-level rhythm only, a useful provisional target is:

- ~55–65% predominantly monochrome;
- ~20–30% controlled single-family signal color;
- ~10–15% strong color-event compositions.

These percentages are not a runtime quota and must not be enforced mechanically. They exist only as an art-direction heuristic until creator acceptance confirms or replaces them.

## Scene-mode hypothesis — INFERRED

- THRESHOLD: near-monochrome / mineral signal
- PROLOGUE: editorial monochrome
- DESCENT: dark field with increasing chromatic contamination
- ARCHIVE: widest media diversity; color follows source material
- MACHINE: technical neutral field + state color
- COSMOLOGY: strongest candidate for deliberate chromatic expansion
- RETURN: bright/quiet field with restrained residual signals

These seven labels describe visual/editorial modes. They do not supersede canonical A–Y topology.

## Anti-patterns

Avoid:
- rainbow color because the subject is "cosmic";
- generic RGB cyberpunk gradients everywhere;
- colorizing Ocín masters without explicit derivative permission;
- using red/green alone as success/failure;
- adding neon merely to make an interface feel technological;
- applying the same violet glow to every scene until scenes become indistinguishable.

## Acceptance question

When twenty KODEX screens are viewed together, they should be visibly different in density, composition and chromatic behavior while still belonging unmistakably to one system.
