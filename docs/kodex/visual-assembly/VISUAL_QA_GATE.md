# KODEX Visual QA Gate v0.2

Every candidate must pass all HARD gates before visual taste is scored.

## HARD gates

- Provenance resolved for every hero/media block.
- Public/export rights respected.
- OCÍN master pixels not repainted, restyled or destructively altered by default.
- Cultural material has source, permission/consultation state and allowed transformations.
- Scientific claims are not inferred from decorative diagrams.
- Critical copy is semantic/live, not trapped in raster.
- Mobile is recomposed, not merely scaled desktop.
- Keyboard/touch equivalence exists where interaction is meaningful.
- Reduced-motion preserves meaning.
- Contrast does not depend on color alone.
- Performance/fallback profile declared.

Any HARD failure blocks promotion regardless of visual quality.

## SOFT score — 0–2 each

1. One dominant visual event.
2. Recipe legibility.
3. Editorial hierarchy.
4. Negative-space control.
5. Signal color discipline.
6. Artwork/interface separation.
7. Scene fit.
8. Novelty without canon break.
9. Typography/content fit.
10. Reconstructability by another agent.

Pass threshold: **16/20 and zero HARD failures**.

## Evidence levels

This QA gate complements, not replaces, the existing Frontier Visual Gate.

- `CONTRACT_PASS` — assembly data/governance invariants validate.
- `BUILD_PASS` — implementation builds.
- `FUNCTIONAL_PASS` — required semantics work.
- `DEVICE_QA_PASS` — required viewports and input/fallback modes pass.
- `FRONTIER_VISUAL_PASS` — visual-convergence review passes.
- `CREATOR_VISUAL_PASS` — Ocín explicitly accepts the direction.

No earlier level implies a later one.
