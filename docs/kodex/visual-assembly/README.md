The intended chain is:

```text
OCN-* authored work/source
+ RCP-* composition recipe
+ bounded KDX-VIS-* editorial/interface primitives
+ optional approved KDX-FX-* live layer
→ Assembly Candidate JSON
→ hard-gate validator
→ renderer
→ device QA
→ Frontier Visual Gate
→ creator acceptance
```
