- Browser evidence reviewed.
- Creator verdict recorded for the corridor as a whole.
- PR ready state only after evidence is current-head.
- Merge only after exact-head green + creator acceptance.
- Deploy only after merged production candidate is smoke-tested.

## Security exclusions
No account/permission/credential changes. No `.claude/settings.json` security cleanup without explicit authorization. No protected-source mutation. No invented SOURCE_IDs or provenance.
